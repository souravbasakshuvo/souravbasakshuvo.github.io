A line follower robot that autonomously navigates a predefined path marked by a line on a surface. Built using an Arduino Uno with TCRT-5000 IR sensors for line detection and an L298N motor driver for motor control. The robot adjusts its speed and direction in real time based on sensor feedback.

## Components
- Arduino Uno — microcontroller
- TCRT-5000 IR Sensors — line detection
- Ultrasonic Sensor — obstacle detection
- L298N Motor Driver — motor control
- Programmed in C++ using Arduino IDE

## Features
- Follows black line on white surface and vice versa
- Real-time speed adjustment based on sensor input
- Obstacle detection via ultrasonic sensor
