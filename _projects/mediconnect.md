MediConnect is an Android telemedicine application developed for the BME 4232 Telemedicine course at KUET. It enables secure, real-time video consultations between healthcare professionals and patients, with support for messaging and medical data sharing.

## Features
- **Video Calling**: High-quality real-time video conferencing via ZEGOCLOUD SDK
- **Secure Messaging**: Chat between doctors and patients
- **Data Sharing**: Share medical images, reports, and prescriptions during consultations
- **Emergency Services**: Quick consultations for urgent cases
- **Multilingual Support**: English, Bangla, and Hindi
- **Firebase Authentication**: Secure sign-up and sign-in with email and password

## Technologies
- Java — Android app development
- Firebase — authentication, real-time database, and storage
- ZEGOCLOUD — real-time video, voice, and chat SDK
- Android Studio — development environment
